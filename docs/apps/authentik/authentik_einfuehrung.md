# authentik: Eine moderne Identity- und Access-Management-Lösung

authentik ist eine Open-Source-Identity- und Access-Management-Lösung (IAM), die eine Vielzahl von Anwendungsfällen abdeckt, von einfachen Anmeldungen bis hin zu komplexen Workflows für Berechtigungen und Zugriffe. Es bietet eine moderne und flexible Plattform für die Verwaltung von Identitäten und den Schutz von Anwendungen.

## Was ist authentik?

authentik ist mehr als nur ein Single Sign-On (SSO) Provider. Es kombiniert verschiedene Funktionen in einer einzigen Plattform:

*   **Identity Provider (IdP):** authentik kann als IdP für verschiedene Protokolle wie OpenID Connect (OIDC), SAML und LDAP fungieren.
*   **Access Management:** Es bietet detaillierte Kontrollmöglichkeiten für den Zugriff auf Anwendungen, basierend auf Rollen, Gruppen, Richtlinien und anderen Kriterien.
*   **Workflow-Engine:** Mit der integrierten Workflow-Engine können komplexe Prozesse für die Benutzerregistrierung, Genehmigungen und andere Aufgaben automatisiert werden.
*   **Password Management:** Funktionen wie Passwort-Resets, Passwortrichtlinien und Multi-Faktor-Authentifizierung (MFA) sind integriert.
*   **API-First-Ansatz:** authentik ist von Grund auf mit einer API entwickelt worden, was die Integration in bestehende Systeme erleichtert.

## Wofür wird authentik eingesetzt?

authentik eignet sich für eine Vielzahl von Anwendungsfällen:

*   **Single Sign-On (SSO):** Ermögliche Benutzern den Zugriff auf mehrere Anwendungen mit nur einer Anmeldung.
*   **Zentrale Benutzerverwaltung:** Verwalte alle Benutzerkonten und Berechtigungen an einem zentralen Ort.
*   **Multi-Faktor-Authentifizierung (MFA):** Erhöhe die Sicherheit durch die Verwendung von MFA mit verschiedenen Methoden wie TOTP, WebAuthn (z.B. YubiKey) oder Push-Benachrichtigungen.
*   **Self-Service-Portale:** Biete Benutzern die Möglichkeit, ihre Passwörter zurückzusetzen, Profile zu verwalten und andere Aufgaben selbstständig zu erledigen.
*   **API-Sicherheit:** Schütze APIs durch OAuth 2.0 und OIDC.
*   **Automatisierung von Workflows:** Automatisierung von Prozessen wie Benutzerregistrierung, Genehmigungen und Provisionierung.

## Vorteile von authentik

*   **Open Source:** Keine Lizenzkosten und volle Transparenz.
*   **Flexibel und anpassbar:** Kann an die spezifischen Bedürfnisse angepasst werden.
*   **Moderne Architektur:** Basiert auf modernen Technologien und Standards.
*   **Umfangreiche Funktionen:** Bietet eine breite Palette von Funktionen für das Identity- und Access-Management.
*   **Aktive Community:** Eine wachsende Community trägt zur Weiterentwicklung bei.
